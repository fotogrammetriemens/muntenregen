# Romeinse Muntenregen

Vang Romeinse munten met de buste en ontwijk de speren. Speel online via GitHub Pages:
https://fotogrammetriemens.github.io/muntenregen/

De gedeelde top 3 staat in Supabase (tabel `scores`). De Project URL en publishable key bovenin `index.html` zijn openbaar bedoeld; de tabel staat alleen lezen en toevoegen toe.
